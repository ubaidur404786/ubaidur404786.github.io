# Portfolio — Ubaid Ur Rehman

Static one-page portfolio (`index.html`), ready for GitHub Pages.

## Publish
1. Create a public repo named `ubaidur404786.github.io` on GitHub.
2. In this folder:
   ```
   git init
   git add .
   git commit -m "Add portfolio site"
   git branch -M main
   git remote add origin https://github.com/ubaidur404786/ubaidur404786.github.io.git
   git push -u origin main
   ```
3. Site goes live at https://ubaidur404786.github.io (Settings → Pages → branch `main` if not automatic).
